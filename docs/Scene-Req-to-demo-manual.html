2 工作流 — 4 阶段

Phase 1 — 批量需求收集（可重复） 场景 1 → 领域检测 → 背景分析 → 结构化分析 → 简版文本（需求名称+总体+FR，便于审核） 场景 2 → ...同上 场景 N → ...同上 每轮后问："是否还有需求？" → 有→下一场景 / 无→ Phase 2 注：简版仅含需求名称/总体/FR；全量 6 段仅在 Phase 4 Markdown 中呈现 │ ▼ Phase 2 — 参考页确认 问："是否有基础页面或参考页面？" 截图 PNG/JPG → 提取布局/配色/组件样式 HTML 文件 → 提取结构/样式/组件模式 文字描述 → "现有XX系统的XX页面" 有 → Mode A 叠加 / Mode B 风格复制 无 → Mode C 全新生成（默认暗蓝工业风） │ ▼ Phase 3 — 合并与验证 合并全部 FR：去重、重编号 FR-1..N、优先级均衡 合并业务背景：统一问题陈述与干系人 图表生成 + 质量验证（5锚点/6段式/CoVe/去重/Demo就绪度） │ ▼ Phase 4 — 三重输出（合并后） ├─→ Markdown 六段式需求文档（合并后） ├─→ 业务系统 Demo HTML（按 Mode A/B/C） └─→ 结构化 JSON

1 批量收集

每轮输入一个场景，对话内返回简版文本（需求名称+总体+功能需求），人工审核后决定是否继续。

输出：简版文本（无文件）

2 参考页确认

收集完毕后，确认是否有基础页或参考页，决定 Demo 的生成模式。

输入：截图 / HTML / 文字描述

3 合并验证

合并全部 FR，去重、重编号，生成图表，执行质量验证。

检查：5锚点/6段式/CoVe/去重

4 三重输出

基于合并结果一次性产出 Markdown + Demo + JSON。

交付：.md + -demo.html + .json
💡
单场景快捷：仅一个场景且 FR ≥ 3 时，Phase 1–2 可一轮完成，直接进入 Phase 3–4。

【功能需求】
  FR-1 xxx（高优） 位置：...；数据：...；...
  FR-2 xxx（中优） ...
（共 N 项）

阶段 4：完整交付（合并后，文件）

#交付物格式内容
1需求文档.md六段式（背景/总体/功能/接口/数据/非功能）+ Mermaid 图表
2业务系统 Demo-demo.html单 HTML，Vue 内联，业务界面+模拟数据+可交互，file:// 双击即用

关键区分：Demo 是业务系统本身的前端原型（统计看板/工单列表/管辖地图等），不是需求文档的展示页。每条 FR 对应 Demo 中的一个可交互功能区，example 字段提供模拟数据。

阶段 1 简版（对话内）

【需求名称】智能浏览情况统计展示 【总体需求】智能浏览情况统计展示：在显示模块中集中展示浏览车站数、异常数、闭环数等，支持多维度查看，口径支持按项目配置。 【功能需求】 FR-1 浏览车站数统计（高优） 统计已覆盖车站数量，支持按日/周/月及线路筛选。 位置：在【智能浏览统计】卡片区首位；数据：按车站ID去重计数；默认开启。 例如：某日覆盖 13 个车站中的 9 个，显示"9/13"及 69%。 FR-2 系统发现异常数统计（高优） 统计系统自动发现的异常总数，支持分类及下钻。 FR-3 人工处理闭环数统计（高优） 统计已闭环数量及闭环率，区分三态。 FR-4 统计维度与可视化（中优） 多维度筛选及图表呈现，支持导出。 （共 4 项）

8 FAQ

Q: 单个场景只有 1-2 个 FR，Demo 会不会太空？

这正是批量收集的价值：先多轮收集场景（每轮简版确认），合并到 6–12 条 FR 后再统一生成 Demo，信息密度才适合做 Dashboard。

Q: 两个 skill 吗？

不是。已合并为单一 skill scene-req-to-demo。阶段 1 的简版文本即为逐条审核，后续合并出全量文档。

Q: Demo 是需求展示页还是业务系统页？

业务系统本身的前端原型（如统计看板、工单列表、管辖地图），带模拟数据与可交互功能，不是把 FR 卡片罗列出来的需求展示页。

Q: 有现有页面怎么办？

在 Phase 2 提供截图/HTML/文字描述，Demo 会叠加新功能或复制原有风格，无则按默认暗蓝工业风全新生成。

Q: Demo 的 file:// 双击空白？

Vue 已内联，无需 CDN；Mermaid 图表区有源码降级。如仍空白，按 F12 查看控制台错误，或改用 python3 -m http.server 8899 后访问 http://localhost:8899/xxx-demo.html。

Q: 给其他 agent 迁移需要传哪些文件？

传整个目录 scene-req-to-demo/（1 主 + 8 资产，共约 70KB）。或运行 scripts/install-skill.sh 自动安装到所有兼容目录。
