# 铁路信号子系统界面传统 — Domain UI Reference

> **用途**：生成 Demo 时按 `domain_info.subsystem` 选用对应子系统的界面骨架与配色，
> 避免"自由发挥出外行界面"。约束版（脚本）用此做布局基线，创意版（LLM）以此为专业下限。
> 安全子系统不适用本文件（安全系统无前端，见 `domain-railway.md` 铁律 2）。

## 通用配色惯例（行业通用，务必遵守）

| 语义 | 颜色 | 变量建议 |
|------|------|----------|
| 占用 / 报警 / 紧急 | 红 | `--status-red` |
| 空闲 / 锁闭 / 正常 | 绿 | `--status-green` |
| 预警 / 注意 / 降级 | 黄/橙 | `--status-yellow` / `--status-orange` |
| 无车 / 常用 / 信息 | 白/蓝 | `--text-primary` / `--status-blue` |
| 进路光带 / 选中 | 青/绿 | `--accent-cyan` |

## ATS — 调度指挥界面

**布局骨架**：`中央=站场图/线路图，左侧=运行图，右侧=报警窗，顶部=工具栏`

- **站场图区（主视觉）**：轨道线 + 区段占用光带（红=占用/绿=空闲）、信号机状态点、道岔开通方向、车次号标签随列车移动
- **运行图区**：时距图（横轴时间/纵轴车站），运行线（实际=实线、计划=虚线），晚点标红
- **报警窗**：按等级分色列表，点击定位到站场图对应位置
- **工具栏**：自动/手动模式切换、进路操作、扣车/跳停、时间范围

**关键交互**：点击区段→悬浮显示占用车次/速度；报警→联动高亮站场图

---

## CTC — 调度集中界面

**布局骨架**：`核心=实际运行图(时距图)，顶部=车次号/命令工具，侧边=站场表示`

- **实际运行图**：横轴时间、纵轴车站，列车运行线，计划线对比，会车/越行点标注
- **车次号窗**：车次号输入/修改/跟踪，与运行线绑定
- **调度命令窗**：命令起草→下达→签收状态流转
- **站场表示**：简化站场图，显示信号/进路/区间状态

**关键交互**：运行图上拖拽调整→生成调整建议；命令下达需二次确认

---

## MSS / CSM — 集中监测界面

**布局骨架**：`左=设备树导航，右=曲线/波形主区，底=实时报警条`

- **设备树**：车站→系统（联锁/轨道电路/转辙机/信号机）→具体设备，逐级展开
- **曲线主区**：转辙机动作电流曲线（最经典）、轨道电压、灯丝电流；支持历史对比与波形回放
- **实时报警条**：滚动报警，分级分色，点击跳转对应设备曲线
- **报表区**：日报/月报、分路不良处所统计

**关键交互**：选设备→加载对应曲线；时间轴拖动回放；越限值标红

---

## IOM — 智能运维界面

**布局骨架**：`仪表盘网格 / 运维看板 / 工单列表三选一，暗色大屏风格`

- **健康评分卡**：设备健康度评分、趋势、TOP 风险设备
- **故障统计**：按等级/专业/时间的柱状/饼图，频发异常排行
- **工单管理**：工单列表（状态流转：待派/处理中/已闭环）、看板泳道
- **检修计划**：日历视图，计划/实际对比
- **备件库存**：TOP3 缺件预警、库存水位

**关键交互**：评分卡钻取→设备详情→历史故障；工单状态一键流转

## 分区拓扑（FR 语义落位用）

> **用途**：每个子系统定义一组**功能区**（整体布局架构的组成单元）。`render-demo.py` 用 `keywords` 把分析出的 FR **按语义落位**到对应分区（尽力匹配，不保证 100% 精准；给了参考模板才可精准）。每个分区有 `type`，用于下段"整体效果示意"的拟真渲染。
> **分区类型 type**：`stationmap`(站场/线路图) `diagram`(时距/运行图) `curve`(曲线/波形) `chart`(图表) `table`(表格) `list`(列表) `kpi`(指标卡) `kanban`(看板) `alarm`(报警) `tree`(设备树)

## 与 Demo 生成的对应（两段式）

> **约束版（render-demo.py）两段结构**（安全场景除外，安全走阐述图）：
> - **上段「需求范围视图」**：渲染子系统**整体布局架构**（全部分区），把本次 FR **按语义落位**到对应分区并**高亮**，无 FR 落入的分区标为**虚线灰格「非本次需求范围」**——凸显"这几条需求落在整个系统的哪几块"，**不硬把需求铺满整页**。
> - **下段「整体效果示意」**：同一架构的**生产级拟真观感**——全部分区按 `type` 用拟真模板+示意数据渲染，呈现"整页做出来大致长什么样"。数据标注「示意」，仅作视觉效果。
>
> **创意版（LLM + 本文件）**：以约束版为专业下限，可换架构/风格做差异化（对应 A/B 双轨）。

| subsystem | 角色徽标 | 说明 |
|-----------|----------|------|

| ats | 列车调度员 | 两段式，按 ATS 分区拓扑 |
| ctc | 列车调度员 | 两段式，按 CTC 分区拓扑 |
