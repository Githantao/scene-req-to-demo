## ⚠️ 可行性约束（必须遵守）

创意版是**自包含单 HTML + file:// 打开**，因此：

- 灵感模式必须能用 **CSS / SVG / 内联 Vue** 实现，或明确标注"需 CDN/网络"
- **禁止**引入需构建的工具链（无 npm/webpack）；Vue 用 `vendor/vue.global.prod.js` 内联
- 图表优先用**纯 CSS 手绘 / SVG**（约束版已示范），如需 ECharts 等须标注"需网络"并给降级方案
- 每个灵感点给**降级方案**：无网络时用静态模拟数据 + 注释说明真实场景接什么数据源

## 灵感模式库（按信息化技术趋势）

### 1. 大屏可视化（适用 ATS / CTC / IOM）
- **模式**：暗色仪表盘、GIS 线路图叠加、实时流式刷新、跳动数字
- **实现**：CSS Grid 网格 + SVG 线路图 + `setInterval` 模拟数据刷新
- **降级**：静态数值 + 注释"真实场景接 WebSocket 实时推送"

### 2. 实时通信与动态光带（适用 ATS / CTC）
- **模式**：车次号移动动画、区段占用流光、进路光带渐变
- **实现**：CSS `@keyframes` + Vue `v-for` 渲染区段数组 + 定时更新位置
- **降级**：固定位置标注"真实场景由列车定位报文驱动"

### 3. 数字孪生 / 空间定位（适用 MSS / IOM）
- **模式**：伪 3D 卡片、设备空间定位、悬浮详情
- **实现**：CSS `transform: perspective/rotateX` 做伪 3D，绝对定位设备点 + 悬浮卡片
- **降级**：平面图标注"真实场景接 BIM+GIS/三维模型"

### 4. 智能交互：关联钻取（全子系统）
- **模式**：点击设备→报警→工单逐级钻取；时间轴回放；全局搜索
- **实现**：Vue 状态机 + 面包屑 + `v-show` 层级切换；`<input type="range">` 做时间轴
- **降级**：固定两层钻取 + 注释"真实场景接图数据库关联查询"

### 5. AI 增强（适用 IOM / MSS）
- **模式**：侧边"AI 助手"对话框、故障预测置信度标注、报警智能摘要
- **实现**：静态对话气泡 + 预测卡片带置信度进度条（纯 CSS）
- **降级**：模拟回复 + 注释"真实场景接 LLM/预测模型，置信度必须标 [假设]"
- ⚠️ 预测准确率等指标**禁止编造确定值**，标注来源或 `[假设]`（铁律 3）

### 6. 可配置化（适用 IOM）
- **模式**：拖拽看板、用户自定义布局、布局方案切换
- **实现**：提供 2-3 种预设布局按钮切换（`grid-template` 切换），呼应 `configurable` 锚点
- **降级**：预设切换 + 注释"真实场景接低代码拖拽引擎"

### 7. 多端适配（适用 IOM / MSS）
- **模式**：一键切"大屏/桌面/移动"三种布局、响应式
- **实现**：CSS 媒体查询 + 布局切换按钮（改 `body` class）
- **降级**：桌面布局 + 注释"真实场景响应式适配"
